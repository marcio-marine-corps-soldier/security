# Laboratory Notes

## Project Overview

This laboratory was developed to study phishing techniques from a defensive cybersecurity perspective using the Zphisher framework in an isolated environment.

The primary goal was to understand how phishing campaigns operate and how organizations can better defend against them.

# Observations

During this laboratory, it became clear that phishing attacks rely heavily on human behavior rather than technical vulnerabilities.

Proper user awareness, strong authentication mechanisms, and continuous security training remain essential components of an effective cybersecurity strategy.

---

# Lessons Learned

* Technical documentation is an essential cybersecurity skill.
* Security awareness significantly reduces phishing risks.
* Controlled laboratory environments are valuable for understanding attack methodologies safely.
* Ethical responsibility is fundamental when studying offensive security techniques.
